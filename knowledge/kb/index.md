# 知识

本主题有三块，彼此独立：

- 团队知识库是运行时的产品功能：集合/条目/修订、密级 + 受控 tag 的双轴授权、个人条目经发布申请评审并入全局、条目链接、知识包与关键词注入；有 SQLite 与 PostgreSQL 两套存储实现，由端口统一选择。
- 大纲是另一套按空间组织的块树存储（提交 + 版本、任务、实时编辑、汇报），由 `outline.enabled` 开关控制，默认关闭；其定位正在重新考虑。知识库不受大纲开关影响（开关说明里明确写了"知识库不受影响"，知识库服务代码里没有引用大纲）。
- 仓库知识树是给开发者和 agent 读的代码知识，不是运行时功能，只在这里列出以说明约定。

## 下面有什么

- [团队知识库](knowledge-base.md)：分级 + 分 tag 授权、写时复制版本、知识图谱链接、知识包。
- [大纲](outline.md)：大纲的存储、工具、实时编辑；正在重新定位。
- [仓库知识树](repo-knowledge.md)：本目录：放什么、格式、谁来更新、何时更新。
