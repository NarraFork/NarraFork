Fork a new independent narrator from the current narrator session.

This tool creates a new narrator that runs independently — the parent narrator does NOT wait for it to finish. The new narrator immediately starts processing the message you provide.

Two modes are available:

- "fresh": Create a brand-new narrator with no conversation history. Your message becomes its first input. Use this when the new narrator needs a clean slate for a different task.

- "fork": Fork from the current conversation position, inheriting the message history. Your message is sent as a follow-up in the forked context. Use this when the new narrator should continue from where you are but take a different direction.

Behavior depends on the parent narrator type:

- Chapter-bound narrator: Creates a new chapter (with its own git branch and worktree) forked from the current chapter, plus a new primary narrator for that chapter.
- Standalone narrator: Creates a new standalone narrator (no chapter).

Important notes:
- The new narrator runs completely independently — you will NOT receive its output.
- Use this when you want to delegate a long-running or divergent task to a separate narrator that the user can monitor independently.
- Do NOT use this as a substitute for the Agent tool (subagents). Use Agent when you need the result back in your current conversation.
- This tool is best for spawning parallel workstreams that the user will interact with directly.
