Data mapping (frontend/components/providers/provider-presets.ts):
- Keep only provider id, name, compatible API base URLs and default chat protocol.
- anthropic-messages maps to anthropic-messages; openai-responses maps to
  openai-responses; openai-chat-completions maps to completions-compatible;
  google-generate-content maps to gemini-compatible.
- Keep concrete URLs for adapter families anthropic, openai-compatible, openai,
  open-responses and google. The ordinary API-key compatible families deepseek,
  openrouter, groq, togetherai, xai, xai-responses and cerebras are mapped onto
  the corresponding generic protocols, without copying their adapter code.
- Remove trailing slashes. Anthropic bases end in /v1; Gemini bases end in
  /v1beta. OpenAI bases receive /v1 unless they already contain a versioned
  path segment (for example /api/v3, /api/paas/v4, /v3/openai or /api/v1).
  NarraFork appends /messages, /responses, /chat/completions or /models/...;
  therefore these URLs do not depend on SDK-specific prefix handling.
- Keep the upstream default when included; otherwise use the first compatible
  endpoint. Ollama is an explicit local compatibility override: only its
  OpenAI-compatible http://localhost:11434/v1 is exposed, not native /api/chat.
  A second local compatibility override adds OpenAI Chat Completions at
  https://api.openai.com/v1; upstream lists only Responses for this provider,
  and Responses remains the default.
- Add NarraFork-authored Chinese search aliases (for example SiliconFlow,
  ZhiPu, DeepSeek, Bailian, Doubao, Moonshot and StepFun Chinese names) and
  common English aliases. These aliases are local usability metadata, not
  copied upstream fields; original provider ids and display names are retained.
- Exclude Azure, Bedrock, Vertex AI, Copilot, OpenAI Codex, Claude Code, Grok CLI,
  native Ollama, ComfyUI, missing URLs, and unapproved specialized adapter
  families (cherryin, aihubmix, dmxapi, newapi, mistral, perplexity, voyage,
  gateway). NUG and the custom option are UI actions, not registry records.
- Do not carry model data, website metadata, referral links or promotion URLs.
