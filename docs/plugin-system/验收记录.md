## 安全边界

- UI shell 由宿主生成，iframe 仅 `sandbox="allow-scripts"`，不含 `allow-same-origin`。
- CSP 默认拒绝；`connect-src 'none'`，禁止 frame/worker/object/form/media；资源路径、manifest entry、hash、realpath、symlink、traversal 和字节上限均 fail-closed。
- 每个 UI panel 独立 nonce/MessageChannel/session；请求 ID、版本协商、超时、取消、payload 上限和 source/nonce/identity 校验均有测试。
- 插件进程使用参数数组，不隐式 shell；Podman profile 包含 rootless、`no-new-privileges`、`cap-drop ALL`、只读根文件系统、`network none`、pids/CPU/内存/tmpfs 限制。
- Ed25519 签名演练使用真实 `generateKeyPairSync`、`PluginTrustKeyring` 与 digest-bound payload，验证 `trusted=true`。
